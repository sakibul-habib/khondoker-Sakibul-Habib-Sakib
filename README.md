# KHONDOKER SAKIBUL HABIB SAKIB - Executive Portfolio

A lightweight, high-performance portfolio website built exclusively with:
- **Pure HTML5**
- **Pure CSS3** (Custom executive dark & light themes)
- **Bootstrap 5.3.3** (Responsive grid, components, and modal)
- **Vanilla JavaScript** (No React, no Node.js, no build tool required)
- **Three.js WebGL Engine** (Executive 3D parametric horizon wave lattice)

---

## ⚡ 1-Click Execution in VS Code & Live Server

Because this website uses **pure HTML, CSS, Bootstrap, and JavaScript**, it does not require any compilation or build step.

### How to Run with VS Code "Live Server":
1. Open this project folder in **Visual Studio Code**.
2. Right-click **`index.html`** in the file explorer.
3. Click **"Open with Live Server"** (or click **"Go Live"** in the bottom status bar).
4. The website opens and runs immediately with full 3D interactive graphics, theme toggling, and project filtering!

### How to Run Without Any Server:
- Simply **double-click `index.html`** on any computer with Chrome, Edge, Firefox, or Safari. It runs immediately!

## 🌐 Deploy Anywhere Instantly

You can host this website on any platform by simply uploading the files:

1. **GitHub Pages**:
   - Push this repository to GitHub.
   - Go to **Settings** → **Pages** → Source: **Deploy from a branch** (`main` / root `/`).
   - Done!

2. **Netlify**:
   - Drag and drop this folder directly into [app.netlify.com/drop](https://app.netlify.com/drop).

3. **Vercel**:
   - Connect your GitHub repository or deploy with the Vercel CLI (`vercel`).

4. **cPanel / Apache / Nginx / Traditional Web Hosting**:
   - Upload `index.html`, `css/`, `js/`, and `my-passport-photo.png` directly into your `public_html` directory via cPanel File Manager or FTP.

## 🌟 Key Features

- **Executive 3D WebGL Horizon Lattice**: Interactive Three.js background with parametric waves and magnetic mouse perturbation.
- **Dark & Light Mode Switcher**: Built-in toggle with `localStorage` persistence.
- **Interactive Project Filtering**: Instant filtering across Enterprise ERP & POS, Academic & Utility, Web Applications, and APIs & Marketing.
- **Printable 3-Page Official CV**: Bootstrap 5 modal containing a complete, PDF-ready curriculum vitae with a 1-click Print button (`window.print()`).
- **Interactive Contact Form**: Direct message dispatcher with email client integration.
